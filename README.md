# Ghana Open AI Official Website

The official open-source website for **Ghana Open AI** ([https://ghanaopenai.org](https://ghanaopenai.org)).

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com), featuring our open-source models, curated speech/text datasets, and interactive demos.

## Features

- **Models Directory**: 60+ open-source models (speech synthesis, voice conversion, ASR, translation, LLMs).
- **Datasets Directory**: 100+ public datasets across Ghanaian languages, agriculture, healthcare, and reasoning.
- **Demos & Spaces**: Interactive benchmarks, speech synthesizers, and [Ghana Search Engine](https://search.ghanaopenai.org).
- **High Performance**: Pre-rendered static pages with Node/Express production container.

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Deployment

Containerized with multi-stage Docker build and deployed via Coolify on `https://ghanaopenai.org`.
